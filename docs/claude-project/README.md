# BarrioRed — Claude.ai Project Files

Files to set up the **non-code** BarrioRed project on Claude.ai (strategy, content, community, operations, fundraising). Software development stays in the Claude Code workspace.

## How to use

1. Open the Claude.ai project → **Settings / Instructions**.
2. Paste the contents of **`00-PROJECT-INSTRUCTIONS.md`** into the custom-instructions field.
3. Upload files **01–05** to the project **Knowledge** base.

## Contents

| File | Purpose |
|---|---|
| `00-PROJECT-INSTRUCTIONS.md` | The instruction block for the project (role, rules, language, guardrails). |
| `01-vision-and-definition.md` | What BarrioRed is: problem, solution, mission, values, differentiators, pitches. |
| `02-context-and-market.md` | Pilot neighborhood, popular economy, audiences/personas, competition, constraints. |
| `03-product-capabilities.md` | State of the art — full inventory of what the product actually does today. |
| `04-brand-voice-and-content.md` | Neo-Brutalist Tropical brand, Colombian-Spanish voice, content patterns. |
| `05-roadmap-and-projections.md` | Phases, go-to-market, monetization, projections (labeled as targets), replication, impact. |

## Key facts baked in
- Pilot: Parque Industrial, Comuna del Café, Pereira, Risaralda (30,000+ inhabitants).
- Product is **near launch-ready** across all four pillars + first monetization — **no real users/revenue yet**; all numbers are targets.
- User-facing content → **Colombian Spanish, informal "tú"**; strategy/internal → English OK.
